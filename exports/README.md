# Exports

Analytical summary CSV files generated from the cleaned datasets.

| File | Description | Source |
|------|-------------|--------|
| `executive_kpis.csv` | Key performance indicators scorecard | All tables |
| `revenue_summary.csv` | Revenue breakdown by plan tier | subscriptions |
| `churn_summary.csv` | Churn event counts by reason code | churn_events |
| `marketing_summary.csv` | Campaign performance with CTR and CPA | marketing_campaigns |
| `support_summary.csv` | Support ticket metrics by priority | support_tickets |
| `customer_directory.csv` | Full customer listing with key attributes | accounts |
