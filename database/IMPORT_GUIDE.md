## 2. Step-by-Step Deployment & Import Sequence

Execute the following commands from your terminal prompt in the root directory of the project:

### Step 1: Initialize Database & Schema
Create the target database and initialize the `analytics` schema:

```bash
# Connect to postgres server and execute schema setup
psql -U postgres -d postgres -f database/schema.sql
```
* **Expected Output**:
  `CREATE SCHEMA`
  `SET`
  `COMMENT`

---

### Step 2: Create Relational Tables
Create all domain tables in the `analytics` schema:

```bash
psql -U postgres -d b2b_saas_analytics -f database/tables.sql
```
* **Expected Output**:
  `DROP TABLE (multiple)`
  `CREATE TABLE (6 statements)`
  `COMMENT (multiple)`

---

### Step 3: Apply Relational & Domain Constraints
Apply Primary Keys, Foreign Keys, and CHECK constraints:

```bash
psql -U postgres -d b2b_saas_analytics -f database/constraints.sql
```
* **Expected Output**:
  `ALTER TABLE (PKs, FKs, CHECKs)`

---

### Step 4: Import Processed CSV Datasets
Bulk load all 6 processed CSV datasets in exact referential order:

```bash
psql -U postgres -d b2b_saas_analytics -f database/import_data.sql
```
* **Expected Output**:
  `Importing marketing_campaigns dataset... COPY 40`
  `Importing accounts dataset... COPY 500`
  `Importing subscriptions dataset... COPY 5000`
  `Importing feature_usage telemetry dataset... COPY 25000`
  `Importing support_tickets operations dataset... COPY 2000`
  `Importing churn_events dataset... COPY 600`

---

### Step 5: Build B-Tree Performance Indexes
Build B-Tree indexes on foreign keys, dates, and filtering attributes:

```bash
psql -U postgres -d b2b_saas_analytics -f database/indexes.sql
```
* **Expected Output**:
  `CREATE INDEX (multiple)`

---

### Step 6: Create Reporting Analytical Views
Build pre-aggregated business reporting views:

```bash
psql -U postgres -d b2b_saas_analytics -f database/views.sql
```
* **Expected Output**:
  `CREATE VIEW (6 statements)`

---

### Step 7: Run Data Integrity & Validation Audit
Run validation checks to confirm database health:

```bash
psql -U postgres -d b2b_saas_analytics -f database/validation.sql
```
* **Expected Output**:
  `0 rows returned for all error detection checks.`

## 4. Troubleshooting Common PostgreSQL Import Errors

### Error 1: `ERROR: insert or update on table "accounts" violates foreign key constraint "fk_accounts_marketing_campaigns"`
* **Cause**: Attempting to import `accounts` before `marketing_campaigns`.
* **Fix**: Strictly follow the ingestion sequence specified in `import_data.sql` (`marketing_campaigns` $\rightarrow$ `accounts` $\rightarrow$ `subscriptions`).

### Error 2: `ERROR: could not open file "data/processed/marketing_campaigns.csv": No such file or directory`
* **Cause**: `psql` was executed from a subfolder rather than the project root directory.
* **Fix**: Ensure your terminal working directory is set to the project root directory before executing `psql`.

### Error 3: `ERROR: constraint "chk_sub_mrr_positive" is violated by some row`
* **Cause**: CSV data contains negative values for MRR or ARR.
* **Fix**: Verify that you are importing files from `data/processed/` generated by `scripts/generate_marketing_campaigns.py`.

### Error 4: Permission Denied for `COPY` Command
* **Cause**: `COPY` requires PostgreSQL server superuser file permissions.
* **Fix**: The `import_data.sql` script uses `\copy` (client-side psql meta-command), which does NOT require superuser privileges and reads local files relative to the client process.
